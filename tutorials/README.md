# BARISTA tutorials

| file | what you learn |
|---|---|
| `01_blind_test.py` | generate data from a hidden mechanism (the review's Table 8 Poole–Frenkel case) and let BARISTA find it |
| `02_your_data.py` | load your own files in any format, add optional device information, export manuscript figures |
| `03_two_channel.py` | a junction where coherent tunnelling and thermally activated hopping act in parallel |
| `04_single_temperature_trap.py` | why one I(V) curve is not enough: the same data with and without T and d axes |
| `hpc/` | Ibex and Shaheen III job scripts (single node, all cores; job arrays for many samples) |

Run any tutorial with `python tutorials/01_blind_test.py`. The output goes to `tutorial_output/`.
